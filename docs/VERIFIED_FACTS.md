## 2. Key Architectural Discrepancies Resolved

1. **Route Count**: System operates **4** routes (`/IngestMetrics`, `/GetMetrics`, `/GetServers`, `/ExecuteCommand`), not 2 routes.
2. **API Stage**: Deployed under `/Prod` REST API stage (`AWS::Serverless::Api`), with endpoints including the `/Prod/` prefix in CloudFormation outputs.
3. **Spike Threshold**: Agent requires **>= 85.0%** across **>= 2 consecutive cycles** (10 seconds minimum sustained spike).
4. **Guardrail Token Verification**: 8-character SHA-256 confirmation token is calculated and verified **strictly on the Flutter client**; it is neither transmitted nor verified by AWS Lambda. The backend does not enforce token expiry or prevent reuse.
5. **Database Indexing**: The query pattern `WHERE server_id = %s ORDER BY created_at DESC LIMIT 20` requires composite index `(server_id, created_at DESC)`.
